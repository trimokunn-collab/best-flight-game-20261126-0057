A make.fun bounty entry: fly a courier plane for the fictional Cendrawasih
Air across a 12,000 px island chain. Three missions — Ring Run (6 rings),
Parcel Drop (3 rings + 3 village drops with a live landing predictor) and
Storm Courier (5 rings + fuel cans in gusts, rain and lightning) — with a
throttle/pitch/stall flight model, fuel and hull, judged landings, score and
1–3 stars, a full instrument panel, and synth sound. Keyboard, mouse and
touch. Vanilla JS, no network loads in the game itself.

## How to run

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
